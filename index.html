Unofficial SAME Post Tools

Free, unofficial browser tools for SAME Post leaders and members: find events, track Post membership, build newsletter pieces, and turn routine exports into reports. The goal is to bring information and open up insights for Posts of all sizes.

Your files stay on your computer. Every tool here runs entirely in your web browser. Files you open in a tool are read and processed on your own device and are never uploaded, sent, or saved anywhere else. There is no account, no sign-in, and no tracking.

You can check this yourself: each page blocks outside connections, and the code is public on GitHub. Try a tool with your internet turned off; it still works. See Security for how every file and export is checked and how to report a problem.

About

SAME Post Tools grew out of the Industry Days list that Bobbi Jo Lang builds by hand, on her own time, every week, so Posts can plan their events around each other and members can plan their attendance. Her list is the foundation of this site.

The tools grew from an idea of Scott DeGaro's: group events that fall in the same week and region into one trip, first tried as a Gulf Coast trip in December 2026. Scott, a member of the SAME Membership Community of Interest, built them with the help of AI tools. The other tools formalize work Scott was already doing for his own Post, so any Post can use them.

Send feedback or get email updates. Questions, suggestions, or problems: same.post.tools@gmail.com

Help build SAME Post Tools

SAME Post Tools is built by volunteers for Posts. You do not need to write code to help.

  • Report a problem or suggest an idea. Use the feedback form (no account needed, not published), the public problem and idea forms on GitHub, or email same.post.tools@gmail.com. Never include member names, email addresses, rosters, or exports in a report.
  • Try a tool with your Post. Open your own Post's files in a tool and tell us what is wrong, missing, or confusing. Your files stay on your computer while you test.
  • Review the code. Every page that runs in your browser is public in the SAME Post Tools repository on GitHub. Reviewers can check the outside-connection block at the top of each page and the checks that run on every file a tool opens and every export it makes.
  • Suggest a change to the code. Pull requests are welcome as proposals. The pages are built from a separate working copy, so an accepted change is applied there by hand, credited to you, and the pull request is then closed.

Spread the word

  • Share it with your Post. Show the tools to your Board, your newsletter editor, and whoever plans your events.
  • Tell us what helps. Which tools your Post uses, and which you would use next, decides what gets built.

Security

Nothing you open in a tool leaves your computer. Each page blocks outside connections; the only exception is the events finder, which reads its own event list from this site. Every file a tool opens is checked before it is used, and every export is checked for contact details before it leaves your computer.

If you find a weakness, please report it privately, not in a public issue. Read the security policy or report a vulnerability.
